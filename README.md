# Investigation Platform - GitHub Deployment Package

## Quick Start

1. Create GitHub repo at: https://github.com/new
   - Name: investigation-platform
   - Public
   - Create repository

2. Run the deployment script:
   - Windows: Double-click `QUICK-PUSH.bat`
   - Mac: Run `./QUICK-PUSH.sh`

3. Paste your GitHub repo URL when prompted

4. Enable GitHub Pages:
   - Settings → Pages → Source: main branch → Save

5. Your site: https://YOUR-USERNAME.github.io/investigation-platform/
